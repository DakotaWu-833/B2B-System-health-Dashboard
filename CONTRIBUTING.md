# Contributing

## Branches

- `main` contains stable, demonstrable work.
- `develop` is the Sprint integration branch.
- Create one branch per Jira issue, for example `feature/SP1-04-authentication`.
- Do not commit feature work directly to `main`.

## Pull requests

Every pull request should:

1. Include the Jira issue ID in its title.
2. Explain the change and how it was tested.
3. Meet the issue acceptance criteria.
4. Avoid committing credentials or local environment files.
5. Be reviewed by at least one other team member before merge.

## Definition of Done

An issue is Done only when its acceptance criteria pass, relevant tests pass, documentation is updated, the Jira issue links to the pull request, and the integration branch still builds after merge.
